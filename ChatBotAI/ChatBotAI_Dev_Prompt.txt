WHAT YOU ARE BUILDING:
A Flask web application module that aggregates guest messages from multiple
platforms (Email, WhatsApp, Airbnb, Booking) into a single inbox, with an AI
assistant that:

1. Auto-responds to guests when the owner is unavailable
2. REMEMBERS every guest permanently (names, family, pets, preferences)
3. Personalizes responses based on stored guest history
4. Learns from ALL conversations, even when owner is chatting manually

BUSINESS CONTEXT:
- Client is an Airbnb host with multiple apartments
- Guests contact via Email, WhatsApp, Airbnb chat, Booking chat
- Need unified view + AI assistance + guest memory

================================================================================
                         CRITICAL FEATURE: GUEST MEMORY
================================================================================

The most important feature is PERSISTENT GUEST MEMORY. The system must:

1. EXTRACT information from every message automatically using the AI:
   - Guest names
   - Family members (names, relations)
   - Pets (names, types)
   - Preferences (room type, check-in time, dietary needs)
   - Special requests
   - Complaints and feedback

2. STORE all extracted information in the GuestDetail table permanently

3. RETRIEVE guest profile when generating AI responses

4. INJECT profile into AI prompts for personalized responses

EXAMPLE FLOW:
```
[First Contact]
Guest Maria: "Hi, I'm traveling with my son Lucas and our dog Max"
System: Extracts {family: "Lucas (son)", pet: "Max (dog)"} → Stores in DB

[6 Months Later - Maria Returns]
Guest Maria: "Hello, I'd like to book again"
System: Retrieves Maria's profile → Injects into AI prompt
AI Response: "Welcome back Maria! Will Lucas and Max be joining you?
             We have a pet-friendly ground floor apartment perfect for dogs!"
```

DUAL-MODE OPERATION:
- AUTO MODE: AI responds AND extracts info
- MANUAL MODE: Owner responds, AI STILL extracts info silently

The AI learns from 100% of conversations, not just automated ones.

1. ai_service.py

2. memory_service.py

3. gmail_service.py

   - send_email(to, subject, body) - Send email response
   - Setup OAuth2 authentication

4. message_router.py
   - Central hub connecting all services
   - Routes incoming messages through the pipeline
