                           1. PROJECT OVERVIEW
================================================================================

BUSINESS CONTEXT:
- Owner manages multiple Airbnb apartments
- Listings on: Airbnb, Booking.com, and personal website
- Guest communication via: WhatsApp, Email, Airbnb chat, Booking chat
- Current problem: Messages scattered across platforms, hard to track

SOLUTION:
A unified messaging dashboard with AI-powered auto-responses and persistent
guest memory, integrated into the existing FlaskApp project.

CORE VALUE PROPOSITION:
- Single inbox for all guest communications
- AI assistant that remembers every guest
- Personalized responses based on guest history
- Auto-response capability when owner is unavailable

================================================================================
                           2. KEY FEATURES
================================================================================

FEATURE 1: UNIFIED INBOX
-------------------------
- Aggregate messages from all platforms into one interface
- Display conversations in a single, organized view
- Filter by platform, guest, date, or status
- Mark conversations as handled/pending/urgent

FEATURE 2: GUEST MEMORY SYSTEM (CRITICAL)
-----------------------------------------
The AI maintains persistent memory of all guests across all interactions.

How it works:
  1. Every conversation (AI or human-managed) is analyzed
  2. Important details are extracted automatically:
     - Guest name and contact info
     - Family members (names, ages)
     - Pets (type, name)
     - Preferences (room type, check-in time, dietary needs)
     - Past stays and feedback
     - Special requests or complaints
  3. Information stored in guest profile database
  4. Profile retrieved and injected into AI context for future chats

Example scenario:
  [First visit]
  Guest: "I'm Maria, traveling with my son Lucas and our dog Max"
  AI extracts: { name: "Maria", family: [{name: "Lucas", relation: "son"}],
                 pets: [{name: "Max", type: "dog"}] }

  [Return visit - 6 months later]
  Guest: "Hi, I'd like to book again for next weekend"
  AI retrieves Maria's profile and responds:
  "Welcome back Maria! We'd love to host you again. Will Lucas and Max
   be joining you? We have a ground-floor apartment that's perfect for
   dogs - Max would have easy garden access!"

FEATURE 3: DUAL-MODE AI OPERATION
---------------------------------
Mode A - AUTO-RESPONSE (Owner away):
  - AI fully handles the conversation
  - Responds to inquiries, provides information
  - Can handle bookings (with configured limits)
  - Escalates complex issues to owner

Mode B - OBSERVER (Owner chatting):
  - AI does NOT respond
  - AI STILL monitors and extracts information
  - Guest profile continuously updated
  - Memory grows from ALL interactions

This ensures guest memory is built from 100% of conversations, not just
automated ones.

FEATURE 4: SMART RESPONSES
--------------------------
- Context-aware replies based on guest history
- Personalized offers (pet-friendly rooms, family discounts)
- Consistent tone and information across all platforms
- Multi-language support (if needed)

                           3. SYSTEM ARCHITECTURE
================================================================================

HIGH-LEVEL OVERVIEW:

+------------------+     +------------------+     +------------------+
|   MESSAGING      |     |    FLASK APP     |     |    LOCAL AI      |
|   PLATFORMS      |---->|    (Backend)     |---->|    (Ollama)      |

COMPONENT BREAKDOWN:

1. MESSAGE AGGREGATOR
   - Connects to each platform's API
   - Normalizes messages to common format
   - Routes incoming messages to processing pipeline

2. GUEST DATABASE
   - Stores guest profiles with all extracted information
   - Links conversations across platforms (same guest, different channels)
   - Tracks booking history and preferences

3. MEMORY EXTRACTION ENGINE
   - Analyzes every message using the local LLM
   - Extracts structured data (names, dates, preferences)
   - Updates guest profiles automatically

4. CONTEXT INJECTION SYSTEM
   - Retrieves relevant guest profile for incoming messages
   - Builds AI prompt with guest history and context
   - Ensures personalized, informed responses

5. RESPONSE GENERATOR
   - Uses local LLM (Ollama) to generate responses
   - Follows configured tone and business rules
   - Can be toggled on/off per conversation

6. WEB DASHBOARD
   - Unified inbox interface
   - Guest profile viewer/editor
   - AI settings and controls
   - Analytics and reporting

================================================================================
                           4. DATABASE SCHEMA
================================================================================

TABLE: guests
--------------
- id (primary key)
- name
- email
- phone
- whatsapp_id
- airbnb_id
- booking_id
- first_contact_date
- last_contact_date
- total_stays
- notes
- created_at
- updated_at

TABLE: guest_details
--------------------
- id (primary key)
- guest_id (foreign key)
- detail_type (family_member, pet, preference, allergy, etc.)
- detail_key (name, type, value identifier)
- detail_value (actual value)
- confidence_score (how certain the AI is about this info)
- source_message_id (which message this came from)
- extracted_at

TABLE: conversations
--------------------
- id (primary key)
- guest_id (foreign key)
- platform (email, whatsapp, airbnb, booking)
- platform_conversation_id
- status (active, closed, pending)
- ai_enabled (boolean - is auto-response on?)
- created_at
- updated_at

TABLE: messages
---------------
- id (primary key)
- conversation_id (foreign key)
- sender_type (guest, owner, ai)
- content
- platform_message_id
- sent_at
- processed (boolean - has AI extracted info?)
- created_at

TABLE: properties
-----------------
- id (primary key)
- name
- address
- description
- amenities (JSON)
- pet_friendly (boolean)
- max_guests
- bedrooms
- created_at

TABLE: bookings
---------------
- id (primary key)
- guest_id (foreign key)
- property_id (foreign key)
- platform
- check_in_date
- check_out_date
- total_guests
- special_requests
- status
- created_at

TABLE: ai_settings
------------------
- id (primary key)
- setting_key
- setting_value
- description

                           7. AI PROMPT STRATEGY
================================================================================

PROMPT TEMPLATE FOR RESPONSES:

```
You are a helpful assistant for [Property Name], an Airbnb rental business.

GUEST PROFILE:
- Name: {guest_name}
- Previous stays: {stay_count}
- Family: {family_members}
- Pets: {pets}
- Known preferences: {preferences}
- Past interactions summary: {history_summary}

CURRENT CONVERSATION:
{recent_messages}

NEW MESSAGE FROM GUEST:
{new_message}

INSTRUCTIONS:
- Respond warmly and professionally
- Reference relevant details from their profile naturally
- If they're a returning guest, acknowledge this
- Provide accurate information about our properties
- If unsure about something, offer to check and get back to them

RESPONSE:
```

PROMPT TEMPLATE FOR INFO EXTRACTION:

```
Analyze this conversation message and extract any important guest information.

MESSAGE:
{message_content}

Extract the following if mentioned (return as JSON):
- guest_name: string or null
- family_members: [{name, relation, age}] or []
- pets: [{name, type}] or []
- preferences: [{type, value}] or []
- dates_mentioned: [{check_in, check_out}] or []
- special_requests: [string] or []
- complaints: [string] or []
- positive_feedback: [string] or []

Only include fields that are explicitly mentioned. Do not assume or infer.

JSON OUTPUT:
```
