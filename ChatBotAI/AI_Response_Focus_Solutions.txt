================================================================================
CHATBOTAI - SOLUCIONES PARA PROBLEMA DE ENFOQUE DEL AI
================================================================================
Fecha: 27 de marzo 2026
Problema: El AI responde a mensajes antiguos (ej. Check-in) en lugar del 
          mensaje más reciente del guest (ej. "Dónde está la Parkkarte?")

================================================================================
DIAGNÓSTICO DEL PROBLEMA
================================================================================

El AI pierde el foco del mensaje más reciente por 3 razones principales:

1. SOBRECARGA DE CONTEXTO (1,500-2,500 tokens en system prompt)
   - Para modelos pequeños (qwen3:8b), demasiado contexto causa "attention 
     dilution" — el modelo "olvida" cuál era la pregunta real
   - A pesar del Smart Context Filter, el prompt aún incluye:
     * Guest Profile (6-15 líneas)
     * Property Details (5-10 líneas)
     * Reservation Info (4-8 líneas)
     * Knowledge Base filtrado (5-15 entradas)
     * Host Instructions (variable)
     * Already Resolved topics (hasta 8)
     * Conversation Summary (hasta 300 palabras)
     * Past Corrections (hasta 10)
     * Conversation Log (últimos 10 mensajes @ 150 chars c/u)

2. POSICIÓN DE LA TAREA EN EL PROMPT
   - El === YOUR TASK === está al FINAL del system prompt
   - Para modelos pequeños, el contenido del system prompt compite por 
     atención con el user message
   - El modelo puede "perderse" antes de llegar a la instrucción de la tarea

3. KEYWORDS DEL CONTEXT FILTER PUEDEN FALLAR
   - Si el mensaje usa palabras muy cortas o no está en las stop words
   - El filtro puede devolver KB entries genéricas (FAQ/general fallback)
   - Puede incluir información de check-in porque es categoría común
   - El profile filtering puede no activarse sin keywords específicas

@classmethod
def detect_intent(cls, message: str) -> Optional[str]:
    """Detect primary intent from guest message using keyword matching.
    
    Returns:
        Intent name (str) or None if no clear intent detected
    """
    if not message:
        return None
    
    msg_lower = message.lower()
    
    # Score each intent by keyword matches
    scores = {}
    for intent, keywords in cls.INTENT_KEYWORDS.items():
        score = 0
        for keyword in keywords:
            if keyword in msg_lower:
                # Longer keywords get higher weight (more specific)
                score += len(keyword)
        if score > 0:
            scores[intent] = score
    
    if not scores:
        return None
    
    # Return intent with highest score
    best_intent = max(scores.items(), key=lambda x: x[1])
    # Only return if score is significant (at least 5 chars matched)
    if best_intent[1] >= 5:
        return best_intent[0]
    
    return None

@classmethod
def _filter_knowledge_entries(
    cls,
    entries: List[Dict[str, Any]],
    message_keywords: Set[str],
    intent: Optional[str] = None,  # NUEVO
    max_entries: int = 5
) -> List[Dict[str, Any]]:
    """Filter KB entries by intent first, then by keyword relevance."""
    
    # Si hay intent detectado, filtrar SOLO entradas relacionadas
    if intent:
        intent_entries = []
        for entry in entries:
            category = entry.get('category', '').lower()
            label = entry.get('label', '').lower()
            
            # Match by category or label containing intent keywords
            if intent in category or intent in label:
                intent_entries.append(entry)
            # También check si alguna keyword del intent está en la entry
            elif cls.INTENT_KEYWORDS.get(intent):
                for keyword in cls.INTENT_KEYWORDS[intent]:
                    if keyword in label or keyword in entry.get('value', '').lower():
                        intent_entries.append(entry)
                        break
        
        # Si encontramos entries del intent, usar SOLO esas
        if intent_entries:
            logger.debug(f"[CONTEXT FILTER] Intent filter: {len(intent_entries)} entries match '{intent}'")
            entries = intent_entries
    
    # Continuar con scoring normal...
    if not message_keywords:
        return cls._fallback_entries(entries, 3)
    
    scored = []
    for entry in entries:
        score = cls._score_entry(entry, message_keywords)
        if score > 0:
            scored.append((score, entry))
    
    if not scored:
        return cls._fallback_entries(entries, 3)
    
    scored.sort(key=lambda x: x[0], reverse=True)
    return [entry for _, entry in scored[:max_entries]]

AGENTES ESPECIALIZADOS:
----------------------

1. KB RETRIEVER AGENT (Búsqueda Semántica)
   ----------------------------------------
   Tarea: Buscar las 2-3 KB entries MÁS relevantes usando embeddings
   Implementación: sentence-transformers (gratis, local, sin AI)
   Velocidad: < 100ms para 100 KB entries
   Precisión: Alta (similitud semántica > keyword matching)
   
   Ventajas vs Context Filter actual:
   - No depende de keywords que pueden fallar
   - Entiende significado semántico ("Parkkarte" vs "parking")
   - Escala a miles de entries sin problema
   - No usa tokens de AI (embeddings = matemática pura)

2. RULES AGENT (Guardián de Políticas)
   ------------------------------------
   Tarea: Check si hay reglas/restricciones críticas aplicables
   Prompt: ~100 tokens (solo reglas relevantes)
   
   Ejemplos:
   - Escalación automática si el guest menciona "precio" o "booking change"
   - Nunca inventar WiFi passwords, códigos de puerta
   - Mencionar alergias si el tópico es comida/cocina

3. INTENT DETECTOR
   ---------------
   Tarea: Identificar QUÉ pregunta el guest (parking, wifi, check-in, etc.)
   Implementación: Keyword matching con scoring
   Ya descrito en Solución #4

4. RESPONSE GENERATOR (AI Final)
   ------------------------------
   Tarea: SOLO generar texto con el contexto ya filtrado
   Prompt: ~300-500 tokens (vs 1,500-2,500 actual)
   Resultado: Enfoque perfecto en el mensaje actual

    ) -> List[Dict[str, Any]]:
        """Retrieve top-k most relevant KB entries using semantic similarity.
        
        Args:
            query: Guest's message
            knowledge_entries: List of KB entry dicts
            top_k: Number of entries to return
            min_similarity: Minimum cosine similarity threshold (0-1)
            
        Returns:
            List of top-k most relevant KB entries
        """
        if not query or not knowledge_entries:
            return []
        
        # Encode the query
        query_embedding = self.model.encode(query, convert_to_numpy=True)
        
        # Calculate similarities
        similarities = []
        for entry in knowledge_entries:
            # Create searchable text from entry
            entry_text = f"{entry.get('label', '')} {entry.get('value', '')}"
            entry_id = entry.get('id', id(entry))
            
            # Use cached embedding if available
            if entry_id in self.embeddings_cache:
                entry_embedding = self.embeddings_cache[entry_id]
            else:
                entry_embedding = self.model.encode(entry_text, convert_to_numpy=True)
                self.embeddings_cache[entry_id] = entry_embedding
            
            # Cosine similarity
            similarity = np.dot(query_embedding, entry_embedding) / (
                np.linalg.norm(query_embedding) * np.linalg.norm(entry_embedding)
            )
            
            if similarity >= min_similarity:
                similarities.append((entry, similarity))
        
        # Sort by similarity and return top-k
        similarities.sort(key=lambda x: x[1], reverse=True)
        top_entries = [entry for entry, sim in similarities[:top_k]]
        
        logger.debug(
            f"[KB RETRIEVER] Query: '{query[:50]}' | "
            f"Found {len(similarities)} matches | "
            f"Returning top {len(top_entries)}"
        )
        
        return top_entries

class AgentSystem:
    """Orchestrates multiple specialized agents for guest response generation."""
    
    def __init__(self):
        self.kb_retriever = KBRetrieverAgent()
        self.rules_checker = RulesAgent()
        self.intent_detector = IntentDetector()
        self.response_generator = ResponseGenerator()
    
    def generate_response(
        self, 
        message: str, 
        conversation_history: List[Dict],
        guest_profile: Dict,
        **context
    ) -> Dict[str, Any]:
        """Coordinate agents to generate a focused response."""
        
        # 1. Detect intent
        intent = self.intent_detector.detect(message)
        logger.info(f"[AGENT SYSTEM] Intent: {intent}")
        
        # 2. Retrieve relevant KB
        kb_entries = self.kb_retriever.retrieve_relevant(
            message, 
            context.get('knowledge_base', []),
            top_k=3
        )
        
        # 3. Check rules
        applicable_rules = self.rules_checker.check(message, intent)
        if 'ESCALATE' in applicable_rules:
            return {'escalate': True, 'reason': applicable_rules}
        
        # 4. Build minimal context
        minimal_context = {
            'guest_name': guest_profile.get('name'),
            'kb_entries': kb_entries[:3],  # Max 3
            'rules': applicable_rules,
            'recent_messages': conversation_history[-2:],  # Solo últimos 2
        }
        
        # 5. Generate response with minimal prompt
        response = self.response_generator.generate(
            message=message,
            context=minimal_context,
            intent=intent
        )
        
        return {
            'response': response,
            'metadata': {
                'intent': intent,
                'kb_used': [e['label'] for e in kb_entries],
                'rules_applied': applicable_rules
            }
        }

import chromadb
from chromadb.utils import embedding_functions

class VectorKnowledgeBase:
    def __init__(self):
        self.client = chromadb.Client()
        # Multilingual embeddings
        self.embedding_fn = embedding_functions.SentenceTransformerEmbeddingFunction(
            model_name="paraphrase-multilingual-MiniLM-L12-v2"
        )
        
        # Create/get collection
        self.collection = self.client.get_or_create_collection(
            name="chatbotai_knowledge",
            embedding_function=self.embedding_fn
        )
    
    def add_entries(self, entries: List[Dict]):
        """Add KB entries to vector DB (una vez al iniciar)."""
        documents = [f"{e['label']}: {e['value']}" for e in entries]
        ids = [str(e['id']) for e in entries]
        metadatas = [
            {'category': e.get('category'), 'property_id': e.get('property_id')} 
            for e in entries
        ]
        
        self.collection.add(
            documents=documents,
            ids=ids,
            metadatas=metadatas
        )
    
    def search(self, query: str, top_k: int = 3, property_id: Optional[int] = None):
        """Semantic search con filtros opcionales."""
        where_filter = None
        if property_id:
            where_filter = {
                "$or": [
                    {"property_id": property_id},
                    {"property_id": None}
                ]
            }
        
        results = self.collection.query(
            query_texts=[query],
            n_results=top_k,
            where=where_filter
        )
        
        return results['documents'][0], results['metadatas'][0]

@classmethod
def _detect_intent(cls, message: str) -> MessageIntent:
    """Detect the primary intent of the message using pattern matching."""
    message_lower = message.lower()
    scores = {}
    detected_entities = []
    
    for intent_name, intent_config in cls.INTENT_PATTERNS.items():
        score = 0.0
        
        # Check patterns
        for pattern in intent_config['patterns']:
            if re.search(pattern, message_lower):
                score += 0.5
        
        # Check entities
        for entity in intent_config['entities']:
            if entity in message_lower:
                score += 0.3
                if entity not in detected_entities:
                    detected_entities.append(entity)
        
        if score > 0:
            scores[intent_name] = min(score, 1.0)
    
    # Get highest scoring intent
    if scores:
        primary = max(scores.items(), key=lambda x: x[1])
        return MessageIntent(
            primary_intent=primary[0],
            confidence=primary[1],
            entities=detected_entities
        )
    
    # Fallback: general question
    return MessageIntent(
        primary_intent='general',
        confidence=0.5,
        entities=detected_entities
    )
